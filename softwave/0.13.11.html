Softwave - v0.13.11

A new version of Softwave is available!

This update includes a firmware update for Wave. It is the first update since 0.13.8, so it also carries the changes from 0.13.9 and 0.13.10 below.

Changes in Wave firmware v1.7.16

  • Fixed a delay of up to several seconds on button presses and releases during the first eight minutes after powering on Wave
  • Fixed long presses not being recognised around eight and a half minutes after power-on

Changes in Wave firmware v1.7.15

  • Fixed Bluetooth MIDI timestamp handling to avoid incorrect packet timing after timestamp rollover

Changes in Wave firmware v1.7.14

  • Fixed a bug where an incorrect Bluetooth packet size was used

Changes in Softwave v0.13.11

  • Fixed an issue on some macOS systems when reconnecting Wave that could lead to a crash
  • Fixed broken Help links
